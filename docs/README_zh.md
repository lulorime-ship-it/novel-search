# 小说搜索下载系统 v2.0

## 简介

Novel Search & Download System 是一款基于 PySide6 + asyncio 的小说搜索与下载工具。通过多搜索引擎自动发现小说站点，抓取目标小说所有章节内容，自动去除广告和重复段落，最终合并为完整的 TXT 文件。同时支持本地书架管理、语音朗读、插件扩展等高级功能。

## 主要功能

- 🔍 **智能搜索** — 支持 Bing/百度/Google/Yahoo/360/搜狗/夸克 七大搜索引擎
- 🌐 **通用源适配** — 自动适配任意小说站点目录页解析，不再局限于特定网站
- 📥 **批量下载** — 异步并发下载，支持勾选特定章节、范围选择、全选/反选
- 💾 **断点续传** — 每章下载后即时存盘，checkpoint.json 跟踪进度，中断后可从断点继续
- 🔄 **重试机制** — 失败章节一键重试，不重复下载已成功章节
- 🧹 **文本整理器** — 去重复行、删广告、智能分段、排版优化，支持关键词删除（整行/整句/仅词）
- 📖 **流式预览** — 大文件逐批加载（100KB/30ms），标题栏实时显示加载进度，不卡UI
- 📚 **书架管理** — 拖入 TXT/EPUB 纳入书架，按标签分类（玄幻、言情、科幻等），追踪阅读进度
- 🎙️ **语音朗读** — 调用系统 TTS 引擎朗读正文，支持语速/音色/音量调节
- 📤 **多格式导出** — 支持 EPUB 2.0 和自包含 HTML 格式导出
- ⭐ **收藏夹** — 保存常用小说，一键打开目录页，搜索历史下拉快速重搜
- 🔄 **自动更新** — 启动时检测 GitHub Release 新版本，一键下载替换
- 🧩 **插件系统** — 允许编写 Python 脚本添加新书源，社区可分享书源脚本
- 🌐 **多语言** — 支持简体中文、English、Español 三种语言
- 💰 **捐献支持** — 通过关于页面查看钱包地址和二维码

## 系统要求

- Windows 10/11
- Python 3.10+ (如从源码运行)
- 网络连接 (用于搜索和下载)

## 快速开始

### 运行 exe

双击 `NovelSearch.exe` 运行程序。

### 从源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

### 1. 搜索小说

在搜索框输入小说名称，点击「搜索」或按回车。系统会通过所选搜索引擎查找小说站点，在结果列表中双击目标小说获取章节目录。

也可直接粘贴小说目录页网址，系统会自动识别站点类型并解析。

### 2. 下载章节

获取目录后，所有章节默认全选。可以通过复选框选择或取消选择特定章节，点击「下载」开始下载。支持「全选」「取消」「反选」批量操作。

下载过程中可随时点击「停止」中断。下载失败的章节会显示红色标记。

### 3. 重试失败章节

下载完成后，如果存在失败章节，「重试失败」按钮会变为可用。点击后系统会重新下载之前失败的章节，成功的章节不会被影响。

### 4. 组合小说

所有章节下载完成后，点击「组合 TXT」将所有有效章节合并为一个完整的 TXT 文件。系统会自动去除广告、重复内容等垃圾信息。

### 5. 预览与导出

在「预览」标签页可以查看已组合的小说内容，也可以通过「打开文件」加载本地 TXT 文件。支持导出为 EPUB 和 HTML 格式。

### 6. 文本整理器

预览页面内置专用小说文本整理器：
- **去重复行** — 通过 Jaccard 相似度算法去除重复段落
- **删广告** — 智能识别并删除网页爬取的广告文本
- **智能分段** — 自动修正不合理的段落分割
- **排版优化** — 统一空行和缩进格式
- **关键词删除** — 输入关键词，支持三种删除模式：删除整行、删除整句、仅删除关键词

### 7. 语音朗读

在预览页面，点击「朗读」按钮，系统调用 Windows TTS 引擎朗读当前文本。可通过滑块实时调节语速、音色和音量。支持暂停/继续/停止操作。

### 8. 书架管理

- 点击「添加书籍」选择 TXT/EPUB 文件，或直接拖拽文件到书架区域
- 通过分类下拉框筛选不同标签的小说
- 双击书籍可直接打开预览
- 支持移除书架中的书籍

### 9. 收藏夹

在搜索页面可将当前小说加入收藏夹，方便后续快速访问。收藏夹支持打开和删除操作。

### 10. 设置

- **输出目录** — 小说文件的保存位置
- **并发下载数** — 同时下载的章节数（建议 3-5）
- **请求间隔** — 请求间隔时间（秒），增加可防止被封 IP
- **搜索引擎** — 选择搜索时使用的搜索引擎
- **相似度阈值** — 超过此值的段落视为重复（0.5-0.99）
- **最小章节字数** — 低于此字数的章节会被标记为内容过短
- **语言** — 界面语言（简体中文/English/Español）

### 11. 插件管理

在「插件管理」标签页可以：
- 安装第三方书源插件（.py 脚本文件）
- 点击「生成示例插件」创建模板，可按需修改适配新站点
- 删除已安装的插件

### 12. 自动更新

启动时自动检查更新，也可在设置页面手动点击「检查更新」按钮。检测到新版本后可一键下载并自动替换重启。

## 技术架构

- **GUI**: PySide6
- **异步网络**: asyncio + aiohttp
- **HTML 解析**: BeautifulSoup4 + lxml
- **搜索引擎**: Bing / 百度 / Google / Yahoo / 360 / 搜狗 / 夸克
- **文本清洗**: 自研去重算法 (Jaccard 相似度)
- **TTS**: QTextToSpeech (Windows SAPI5)
- **打包**: PyInstaller onefile

## 常见问题

**Q: 搜索不到小说怎么办？**
A: 尝试更换搜索引擎或直接粘贴小说目录页的 URL，系统会自动识别并下载。

**Q: 下载中途失败了怎么办？**
A: 点击「重试失败」按钮，未成功的章节会重新下载。

**Q: 如何提高下载速度？**
A: 在设置中增加「并发下载数」，但不要设置过高以免被封 IP。

**Q: 如何添加新的小说站点？**
A: 在插件管理页面生成示例插件，按模板修改解析逻辑即可适配新站点。
