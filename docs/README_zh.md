# 小说搜索下载系统

## 简介

Novel Search & Download System 是一款基于 PySide6 + asyncio 的小说搜索与下载工具。通过 Bing 搜索引擎自动发现小说站点，抓取目标小说所有章节内容，自动去除广告和重复段落，最终合并为完整的 TXT 文件。

## 主要功能

- 🔍 **智能搜索** — 通过 Bing 搜索小说，支持笔趣阁等多个站点，自动模糊匹配
- 📥 **批量下载** — 异步并发下载所有章节，支持暂停/停止/重试
- 🧹 **自动清洗** — 自动去除广告、重复段落、章节标题噪音
- 📖 **内容预览** — 内置 TXT 预览器，无需打开外部编辑器
- 🌐 **多语言** — 支持简体中文、English、Español 三种语言
- 💰 **捐献支持** — 通过关于页面查看钱包地址和二维码

## 系统要求

- Windows 10/11
- Python 3.10+ (如从源码运行)
- 网络连接 (用于搜索和下载)

## 快速开始

### 运行 exe

双击 `NovelSearch.exe` 运行程序。

### 从源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

### 1. 搜索小说

在搜索框输入小说名称，点击「搜索」或按回车。系统会通过 Bing 搜索相关小说站点，在结果列表中双击目标小说获取章节目录。

### 2. 下载章节

获取目录后，所有章节默认全选。可以通过复选框选择或取消选择特定章节，点击「下载」开始下载。

下载过程中可随时点击「停止」中断。下载失败的章节会显示红色标记。

### 3. 重试失败章节

下载完成后，如果存在失败章节，「重试失败」按钮会变为可用。点击后系统会重新下载之前失败的章节，成功的章节不会被影响。

### 4. 组合小说

所有章节下载完成后，点击「组合TXT」将所有有效章节合并为一个完整的 TXT 文件。系统会自动去除广告、重复内容等垃圾信息。

### 5. 预览

在「预览」标签页可以查看已组合的小说内容，也可以通过「打开文件」加载本地 TXT 文件。

### 6. 设置

- **输出目录** — 小说文件的保存位置
- **并发下载数** — 同时下载的章节数（建议 3-5）
- **请求间隔** — 请求间隔时间（秒），增加可防止被封 IP
- **相似度阈值** — 超过此值的段落视为重复（0.5-0.99）
- **最小章节字数** — 低于此字数的章节会被标记为内容过短
- **语言** — 界面语言（简体中文/English/Español）

### 7. 关于

点击「关于」按钮可查看作者信息和捐献支持的二维码和钱包地址。

## 界面预览

程序采用 Catppuccin 暗黑主题，包含四个标签页：

- 🔍 搜索小说
- 📥 下载章节
- 📖 预览
- ⚙️ 设置

## 技术架构

- **GUI**: PySide6
- **异步网络**: asyncio + aiohttp
- **HTML 解析**: BeautifulSoup4 + lxml
- **搜索引擎**: Bing
- **文本清洗**: 自研去重算法 (Jaccard 相似度)

## 常见问题

**Q: 搜索不到小说怎么办？**
A: 尝试直接粘贴小说目录页的 URL，系统会自动识别并下载。

**Q: 下载中途失败了怎么办？**
A: 点击「重试失败」按钮，未成功的章节会重新下载。

**Q: 如何提高下载速度？**
A: 在设置中增加「并发下载数」，但不要设置过高以免被封 IP。
